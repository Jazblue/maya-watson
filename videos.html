Adding Your Videos

To add your own MP4 video files:

  1. Place your video files in the assets/videos/ folder
  2. Name them descriptively (e.g., tennis-match-july.mp4)
  3. Create a new <div class="video-item"> block in this HTML file following the existing pattern
  4. Update the placeholder with your video file path and add a description

For optimal web performance, consider compressing videos to under 10MB each and using the MP4 format with H.264 encoding.
